# WEXTheory — вход в обучение и проверенные знаки в разборе

18 октября 2026. Локальные изменения по замечаниям пользователя со скриншотами.

- У названия WEXTheory удалена добавляемая CSS точка. Сохранены существующие шрифт, название и палитра.
- Кабинет показывает три основных направления: тесты, дорожные знаки и слова. Убраны повторяющиеся промежуточные панели «следующее занятие», «стоит потренировать», отдельные входы в слова/уроки и пустая история. История остаётся в профиле, ошибки доступны по компактной ссылке; сохранённый незаконченный тест по-прежнему предлагается продолжить.
- Статус доступа и число завершённых тестов представлены компактно. Быстрое занятие доступно одной вторичной ссылкой.
- В быстром занятии по умолчанию видны два шага и выбранный урок. Длинный системный список заменён раскрываемым выбором карточек с изображениями знаков. После выбора карточки обновляются название, пояснение и иллюстрации; клавиатурный фокус возвращается на раскрывающую кнопку. Сохраняются отмена нового занятия, первый результат, шаги и текущие раунды.
- В меню оставлен один вход Road signs. Уроки, отдельный урок, тренажёр, каталог и страница знака имеют общие переключатели Lessons / Practice / Catalogue и возврат к обучению. Старые адреса продолжают работать.
- Устранён неверный подбор знаков под вопросом Test01/q02: фразовые совпадения «максимальная скорость» и «населённый пункт» добавляли C55/E55/E56, хотя это не знаки на изображении. Разбор теперь использует только визуально проверенные привязки к изображению: для этого кадра E45. Прежние проверенные кадры учебной программы используются повторно; непроверенные изображения не получают предположительных значков. Привязка не зависит от ID строки вопроса в базе. Условия, ответы и объяснение самого тестового вопроса не менялись.
- По умолчанию страницы открываются светлыми, в том числе вход и восстановление пароля. Явный выбор тёмной темы сохраняется. Изменённые ресурсы имеют новую версию для обновления браузерного кеша.

## Проверки

123 Python-теста прошли, включая четыре новые регрессии для привязки знаков к изображению.

Браузерные сценарии: learning-navigation, study и lesson-quality. Проверяются реальное прохождение слов и урока, сохранение первого итога после перезагрузки и разбора ошибок, отмена нового занятия, отдельные аккаунты, поиск/темы, картинки, клавиатура и диалог увеличения. Изменённые маршруты проверены на ширинах 320/390/1440 в двух темах. Старые браузерные сценарии обновлены для выбора темы карточкой вместо скрытого служебного select.

Изображения и учебные ревизии не заменялись; сохранённые ответы и текущая тестовая база пользователя не сбрасываются. Последний эксперимент с фото на главной не устанавливался. Публикация на рабочий сайт не выполнялась.
